# Analysis of maternal gut and vaginal microbiomes during preventive treatment with sulfadoxine-pyrimethamine

This repository contains command lines used to generate the data presented in the manuscript "Dual-niche profiling identifies selective maternal gut microbiome shifts associated with intermittent preventive treatment with sulfadoxine-pyrimethamine, while vaginal communities remain stable."

Analysis steps are grouped by:
  1) Metagenome quality control and processing
  2) Taxonomic classification
  3) Intra-class correlation coefficient analysis
  4) Metagenome assembly
  5) Strain profiling
